# Data sources, licenses and provenance

Everything not listed here is generated by this repository (seed scenarios in `datagen/scenarios/`, expanded by `datagen/sessions.py`,
executed by the simulator in `datagen/sim/`, error text replayed from commands run in the sandbox — see `datagen/harvest.py`).

| Source | Used for | License | URL | Version / notes |
|---|---|---|---|---|
| tldr-pages | text-to-command (description -> command), `source: "tldr"` | CC BY 4.0 (`LICENSE.md`; scripts/ are MIT, not used) | https://github.com/tldr-pages/tldr | commit `d0da0e654c0a7274ed8f132a45389b6281e21a23`; `pages/common` + `pages/linux` (English), 6,752 pages / 30,227 examples. Attribution: "tldr-pages team and contributors". `{{placeholders}}` are filled with generated names. |
| NL2Bash (Lin et al., 2018) | text-to-command, `source: "nl2bash"` | code GPL-3.0 (not used); **data `data/bash` is MIT** (file `data/bash/LICENSE`, "Copyright (c) 2020 NL2Bash dataset") | https://github.com/TellinaTool/nl2bash (`data/bash/all.nl`, `all.cm`) | 12,607 raw lines -> 9,434 pairs after dedup/length/`\` filters; further filtered by `bash -n`, secrets and flag checks. |
| NLC2CMD (NeurIPS 2020, IBM) | not used separately | no license for a separate data release found (IBM/clai branch `nlc2cmd` contains only starter code; its public training data is NL2Bash) | https://github.com/IBM/clai/tree/nlc2cmd | covered by the NL2Bash entry above. |
| SmolLM2-135M tokenizer | token counting only | Apache-2.0 | https://huggingface.co/HuggingFaceTB/SmolLM2-135M | `tokenizers` + 10 added special tokens (see `datagen/render.py`). |
| Qwen2.5-Coder-7B-Instruct | not used yet (optional scenario generation, phase 3) | Apache-2.0 (model card) | https://huggingface.co/Qwen/Qwen2.5-Coder-7B-Instruct | any LLM-written scenario must pass the simulator + validators. |
| Ubuntu 24.04 container image | real command execution (harvest, validation) | various (distribution packages) | https://hub.docker.com/_/ubuntu | `datagen/docker/Dockerfile`; no network inside the sandbox. |
